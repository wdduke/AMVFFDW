# AMVFFDW Research Notes

## 黏流非连续壁面解析方法研究笔记

本分支用于建立新的系统化研究笔记。

与 main 分支不同，本分支不再按照历史推导顺序组织，而按照物理问题、数学方法和研究逻辑重新构建。

main 分支保存历史手稿；research-note 分支用于形成未来论文和理论研究的基础材料。

---

# 1. Research philosophy

研究目标：

建立非连续壁面约束下壁射流流动的解析或半解析模型。

核心思想：

从统一控制方程出发，根据不同空间区域的物理特征选择不同尺度、渐近假设和数学方法。

基本路线：

```
统一RANS/NS方程
        ↓
区域划分
        ↓
局部坐标建立
        ↓
尺度分析
        ↓
渐近化简
        ↓
相似性分析
        ↓
区域匹配
        ↓
工程模型
```

# 03_region_II_corner

区域2：拐角相互作用区域。

重点研究：

- 二维流动结构；
- 分离与再附；
- 涡尺度；

特别关注：

区域2的特征尺度不应简单继承壁射流厚度，而应根据二维涡结构和几何约束确定。

# 4. Working principle

本分支遵循以下原则：

1. 保留历史推导价值；
2. 不简单复制旧章节；
3. 按研究问题重新组织；
4. 优先建立物理逻辑，再完善数学形式；
5. 最终目标是形成论文级理论框架。
